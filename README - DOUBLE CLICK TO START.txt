APKSANDBOX PRO FOR MAC

1. Extract the ZIP completely.
2. Open the extracted apksandbox-pro folder.
3. Double-click: Start APKSandbox Pro.command
4. On first launch, macOS may block it. If that happens:
   - Control-click the file
   - Choose Open
   - Click Open again
5. The first launch installs the local Python dependencies and may take a few minutes.
6. The browser opens automatically when the app is ready.
7. Keep the Terminal window open. Press Control+C there to stop the app.

The launcher does not require VS Code. VS Code can still be used to inspect or edit the project.
